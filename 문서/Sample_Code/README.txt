소개

Unity 기반 개인 RPG 프로젝트에서 직접 설계하고 구현한 주요 C# 코드 샘플입니다.

시스템 초기화, 씬 및 UI 상태 관리, 플레이어 행동 제어, 아이템 드롭 및 옵션 생성 등 핵심 로직을 중심으로 구성했습니다.

-------------------------------------------------------------------------------------------------------------------------------------------------

코드 구성

1. 시스템 및 데이터 관리

GameManager.cs : 비동기 시스템 초기화, 순차 실행 및 실패 시 재시도 처리

DataManager.cs : 게임 데이터 로딩 및 관리

LanguageManager.cs : 다국어 데이터 및 텍스트 관리

 
2. 씬 및 UI 관리

StateBaseSceneManager.cs : 상태 기반 씬 관리 공통 구조

StateBasePage.cs : UI 페이지 공통 초기화 및 생명주기 관리

IngameSceneManager.cs : 인게임 진행 및 상태 전환 관리

Ingame_002_Inventory.cs : 인벤토리 관련 UI 처리


3. 게임플레이

ItemLootingManager.cs : 가중치 기반 아이템 드롭, 등급 및 랜덤 옵션 생성

Player_000_Base.cs : 플레이어 초기화 및 기본 동작

Player_001_Input.cs : 이동, 공격 및 회피 입력 처리

Player_002_State.cs : 플레이어 상태 전환 및 비동기 작업 취소

Player_003_Status.cs : 데미지, HP 및 사망 처리

플레이어 코드는 partial class를 활용하여 입력, 상태, 데미지 처리 등 기능별로 파일을 분리했습니다.

-------------------------------------------------------------------------------------------------------------------------------------------------

주요 구현 내용

비동기 처리: UniTask와 CancellationToken을 활용한 초기화 및 상태별 비동기 작업 관리

상태 관리: 씬과 플레이어 행동의 상태 기반 전환 구조

게임 로직: 데이터 기반 드롭 확률, 가중치 추첨 및 장비 옵션 생성

참고 사항

본 코드는 프로젝트의 핵심 구현 내용을 발췌한 샘플입니다.
